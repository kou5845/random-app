# ランダム生成アプリ

社内向けのランダム生成ツール（Streamlit製）。

## ローカルで動かす

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

## 公開（Streamlit Community Cloud）

このリポジトリを [Streamlit Community Cloud](https://share.streamlit.io) で
GitHub連携してデプロイする。メインファイルは `app.py`。
